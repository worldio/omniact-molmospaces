## OmniAct's MolmoSpaces data generation pipeline

This repository is adapted from [MolmoSpaces](https://github.com/allenai/molmospaces). Some documentations are out of date, but `docs/embodiment_generation.md` documents the main entry point (`scripts/embodiments/generate_embodiment_dataset.py`) we use for our data generation. There is also a known bug inherited from MolmoSpaces: Some open and close angles are reversed.
